# Complete retrieval trajectories: immutable data backup

The complete corrected DenseOn retrieval trajectory data are backed up and
independently recovered: **26 files / 1,093,911 bytes**. This includes all eight
CSV tables, the actual complete PDF/PNG/SVG figure and figure data, descriptive
stage tables, original completion observations, endpoint evidence and a raw-score
recovery index. Source code and the aggregate bundle containing embedded Python
were explicitly excluded.

**24 checks pass**, including direct arithmetic counterexamples, malformed score
grids, changed/rehashed payloads, missing external anchors and extra symlinks.

The single upload completed at **2026-09-12 11:39:09 UTC**. Revision

`5eb4cceed5c3dbee05d46850ec0d76aedff7d4cc`. The remote audit verifies every new

No source, new root rule, deletion or overwrite was introduced.

All 26 files were anonymously recovered at **11:40:10 UTC**. The copied archived
