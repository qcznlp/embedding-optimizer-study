# DenseOn weight-to-retrieval prediction artifacts

Data-only preservation of two completed analyses. No executable source, model,
training examples or new inference is included. Both use the same sixty corrected
DenseOn checkpoint states and complete fourteen-task macro retrieval outcomes.

`locked/` retains all nine original and five separate exact-measurement features,
four held-learning-rate folds, 840 predictions, 56 fold comparisons and fourteen
pooled decisions. It uses the previously fixed analysis definitions. Its included
execution plan was written after retrieval outcomes were available; it is not a
new preregistration. Original/exact features are not fourteen independent studies.

`sensitivity/` is explicitly exploratory and post-result. It retains all fourteen
features under four recipe comparators and two displacement-conditioned versions:
84 comparisons, 336 folds and 5,040 predictions. It does not amend or replace the
original analysis. Its figures are the final second display version; only this
transport directory is renamed, and every payload preserves its original bytes.

The original baseline RMSE is 2.905349 nDCG@10 points; displacement lowers it to
1.003975. Adding only optimizer-specific raw learning rate to the baseline yields
0.651744, and adding displacement then yields 0.795009. No feature meets the
descriptive improvement criterion under all four unconditioned comparators.
This shows comparator sensitivity, not an optimizer mechanism, significance,
mediation, universally useless geometry or useful embedding dimensions.
The previously computed endpoint results are unchanged.

Independent prediction-verification receipts and copied-source replay receipts
are included for both analyses. Their source paths are historical provenance,
not dependencies required for reading these data. Original archive receipts name
larger archives containing local source; this snapshot deliberately includes
only the selected data payloads enumerated by its own artifact manifest.
The source files and scripts themselves are NOT included or published here.
