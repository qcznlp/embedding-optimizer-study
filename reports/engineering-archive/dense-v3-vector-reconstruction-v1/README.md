## Implemented

The CPU reader authenticates the external local-archive manifest, actual archived contracts and
executing package bytes. It reconstructs all 61 location-free vector plans from the same twelve
run identities and frozen 224-row probe identities, then verifies FP32 arrays and recorded loading
metadata. It never opens old producer, checkpoint or raw-text paths. These checks do not repeat
model encoding, checkpoint tensor validation or raw-text authentication.

The numerical reader uses the unchanged literal FP64 kernel for all 768 coordinate deletions,
80 common random masks and three endpoint rotations. It recomputes each state, writes a separate
new result, compares every per-state CSV and FP64 attribution array exactly, and compares all four
complete aggregate tables. Changed numerical outputs remain available for diagnosis; they never
receive a success receipt. No tolerance or scientific estimand has been changed.
