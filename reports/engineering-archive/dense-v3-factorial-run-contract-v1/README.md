# Genuine-source run binding and complete saved-run reading

This is a **bounded implementation milestone**, not a formal continuation or a
scientific optimizer finding. Primary training was already complete (12 runs,
60 remotely verified checkpoints) and its evaluation continues unchanged. No GPU
was requested by this work. Existing calibration, numerical kernels, primary
source, scientific protocols and manuscript are unchanged.

## What is now connected

Two new package modules bind the actual v3 source checkpoint, the independently
read calibration receipt, the complete branch view, reset operator, order seed,
68-file assembly and fixed runtime to each native checkpoint. All 66 previously
accepted files retain their exact bytes. The source pair remains AdamW 3e-5 and
Muon 3e-4 at step 2345; no outcome reselection occurred.

The actual branch view is exactly 50,000 intact groups, selected once into the
query/positive/seven-negative columns. Both all-21-field identity and actual
nine-text-column values are checked; assigning a matching Dataset fingerprint to
different texts does not pass. The real selected view fingerprint is
`347826279715936e`, parent `64decab17168850e`, and its canonical text digest is
`21206960fb8b9acea333f6cbee6988d85b2dfa3265296dd866e226f514a03648`.

The new internal `RunBoundFactorialTrainer` owns the unchanged primary
`DenseGroupCollator` with `query: ` / `document: ` prompts and the original
five-fraction checkpoint callback. Custom collator/callback injection is refused.
Automatic step-based saving is disabled; the five stages remain
79 / 157 / 235 / 313 / 391. Its inherited training step, loss, sampler,
optimizer, scheduler and native checkpoint/resume hooks are unchanged.

The completion writer requires the full horizon, exact five retained stages,
matching final inference payload and complete Trainer state. It uses exclusive
new receipts and synchronizes ordinary per-rank admission/IO errors before
advancing. It does not promise recovery from a dead rank, failed device or broken
collective. Partial outputs remain on failure; there is no overwrite/retry loop.

The deep reader checks all 134 DenseOn weight tensors, named optimizer moments,
scheduler, static serialized arguments, all four RNG records, full content seals,
final inference package and final epoch. CPU RNG validation uses temporary RNG
objects only; it does not initialize CUDA. `read_complete_run` first rereads both
actual calibration chains through `prepare_run`, so an externally supplied
completion hash alone cannot choose a hidden rate, starting state or dataset.
Artifact verification still returns `scientific_admission=false`.

## API wiring, not an authorized launch command

1. Obtain separately admitted genuine GPU gradient/calibration receipts for both
   fixed source states. Existing `export_gradients` / `replay_calibration` are
   unchanged and remain unexecuted on genuine GPU inputs.
2. Supply explicit `Locations`, both `{path, calibration_binding}` entries and the
   selected source assembly to `prepare_run`. It returns one bound identity and
   the real complete Dataset. Hand-entered learning rates are not that path.
3. Use the unchanged primary model/loss loader and pinned
   `FactorialTrainingArguments`, including the identity's run name, seed and
   hidden LR, auxiliary LR 3e-6, BF16, TF32, non-reentrant gradient checkpointing,
   eight persistent pinned-memory workers/prefetch four, and `save_strategy="no"`.
   Construct `RunBoundFactorialTrainer` without a custom collator or callbacks.
   Any actual source-bound GPU worker/launcher still requires separate admission.
4. After actual training, call `save_run_completion()` on all four ranks and
   retain its external file binding. For interrupted same-run recovery, only an
   externally bound checkpoint with the identical embedded run may be restored.
5. Call `read_complete_run` with the actual calibration bindings and original run
   cell, not a caller-authored replacement identity. Remote durability, complete
   probe/BEIR outcomes, scientific acceptance and publication remain separate.

No scheduler, GPU lease acquisition or formal launch CLI is supplied here. Real

twelve genuine branches and all outcomes remain required. Full cross-host
calibration/run transport and strict final scientific/publication integration are
