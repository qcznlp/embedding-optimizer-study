## What the complete entry is designed to produce

After an unchanged native reader has genuinely authenticated all sixty states,
[complete_trajectory.py](source/complete_trajectory.py) requires that complete
bundle's external SHA-256, the fixed accepted 54-state parent and the already
accepted endpoint readout. Every prior record must remain exactly unchanged.
The intended outputs are all 840 raw scores, 60 checkpoint means, fifteen
four-rate optimizer-stage summaries and twelve observed-range areas, together
with the unchanged endpoint contrast tables. Original endpoint task effects,
intervals and support decisions must exactly agree with the accepted readout.

Observed area retains the original rule: trapezoids between progress 0.2 and
1.0, then divide by 0.8 for the observed-range mean. No initialization is
imputed and no new trajectory significance test is introduced. A separate
exact-rational check covers means and observed-range areas.

[render_trajectories.py](source/render_trajectories.py) verifies every input
table, reconstructs each plotted mean from the complete raw task population,
and retains all four learning rates for each optimizer. All three panels share
axes; the validation-selected recipe is identified without consulting retrieval
to choose it. Intended outputs are PDF, PNG, SVG and the sixty exact plot-data
rows. **No real complete-grid summary or actual figure has run yet.**
