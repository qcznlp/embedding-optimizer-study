actual model state to saved tensors after the declared conversion and checks that encoding changes
no parameters. The matrix reader requires an externally trusted production manifest SHA-256;
rehashing an altered cache is not an authentication anchor. The reader does **not** repeat encoding.

state, task, mask and endpoint rotation. It writes four aggregate tables plus per-state tables and
FP64 native/rotated coordinate arrays. Readback recomputes every feature from authenticated vectors.
