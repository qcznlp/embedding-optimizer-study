# Portable source closure and authoring transport preparation

This goal turn made **progress**, not scientific completion. Its immutable parent is the
[functional inference acceptance](../dense-v3-dimension-inference-v1/validation.json), SHA-256
`ad04bba6f2bec212a35ad6aee6a71aa725bec1f7673a2b524d9fb7cb11e7989b`.
The [plan](plan.md) describes the larger intended numerical reconstruction. **This milestone
implements only its source-closure and authoring-transport foundation.** It does not complete
portable raw-vector reconstruction, primary publication, formal execution or a scientific finding.

## Implemented boundary

The new authoring entry point calls the existing full, checkpoint-backed functional inference
reader before selecting files. On valid future inputs it selects the authenticated vectors,
features, original inference/geometry/outcome/bridge files, declared BEIR result files, saved
validation scores and required source/protocol dependencies. It does not scan entire experiment
or results trees, collect credentials or archive model payloads or raw training/probe text.

Original absolute-location fields remain byte-for-byte provenance. A separate local transport
reader uses only declared relative role paths and an externally trusted manifest hash. It rejects
missing files, changed/rehashed manifests, symlinks, unsafe names and undeclared directories.
Recorded producer locations are never used as a fallback. A locally self-authored hash is not
independent proof that primary inputs are true: valid checkpoint-backed authoring is a separate
requirement, and final publication still requires numerical reconstruction.

The source closure includes the actual seven loaded contracts, geometry entry amendment, their
required direct metadata parents, bound training sources and the bounded Python package source.
It does not recursively copy every historical receipt dependency or the whole workspace.
All old scientific protocols, numerical core, statistical rules and manuscript source are unchanged.
