# Corrected DenseOn v3: complete native weight-analysis snapshot

This snapshot preserves the already measured weight-space outputs for all twelve
corrected primary runs and their sixty checkpoints. It is a data backup, **not a
complete paper, source-code release, optimizer ranking or mechanism finding**.

Contents:

- `approximate/`: original rank-64 sketch measurements, rank-16 retained bases,
  all stage/run records, complete tables and their original manifests.
- `exact/`: complete singular spectra, rank-16 exact bases, all stage/run records,
  complete tables and their original manifests. These are separately declared
  exact measurements, not replacements for the approximate feature definitions.
- `update-map/`: full-dimensional FP64 Gram sufficient statistics for all sixty
  displacements, all three two-dimensional views, complete pair/path tables and
  the original figures and metadata.
- `update-map-readout/`: all sixty-six final-state pair cosines, all 5,310 pair/view
  projection-retention rows and the companion figures.
- `provenance/`: unchanged native completion records, the original map declaration
  and the sixty-checkpoint immutable-revision/file-hash index.
- `artifact_manifest.json`: complete file identities for this snapshot. Authenticate
  its SHA-256 using the project handoff, then verify every downloaded file.

Every numerical file is copied unchanged. There is no code, training text,
invented score or replacement historical result in this snapshot. Source hashes
and original machine paths are provenance, not executable recovery instructions.
Historical `false` admission/release flags remain false; preservation does not
waive a source or scientific gate.

All rates and stages are retained. The measurements cover the 88 main-optimizer
hidden matrices, not all model parameters or useful representation dimensions.
All observed displacement matrices are numerically full rank. More even spectral
energy does not establish more useful embedding dimensions or better retrieval.
The update-map views are descriptive; their two-dimensional distances can hide
large full-dimensional differences. Read the companion tables, not only the map.
Learning-rate cells are not independent training seeds.
