## Reproduce the fragments

Copy this entire directory and use absolute paths plus a new output directory:

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  /usr/bin/python -B /absolute/report/render.py \
  --bundle /absolute/report/bundle \
  --output /absolute/new-fragments
```

Repeat with `--verify` to compare every generated byte with fresh reconstruction,
not just with an editable output digest. Python and NumPy suffice; no project
package, model, GPU or network is imported. The 72 copied inputs are bound to
the exact original actual-data readouts. Their original paths remain provenance,
never fallback lookup locations. `prepare.py` documents how that fixed bundle
was assembled on the experiment host; it is not the portable replay entry point.

The unchanged original nine-feature bridge is numerically replayed during
formatting. Other already independently verified statistics are authenticated
inputs, not claimed as newly recomputed here. Full upstream numerical replays
and larger raw/model restoration remain in their original reports and guides.
This fragment generator supplies no fresh checkpoint admission, GPU-resume
equivalence, factorial inference or source-publication proof.
